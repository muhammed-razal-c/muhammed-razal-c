# Security policy

This is a public GitHub profile README. There is no custom login, user database, API, session, or token system.

## Secure defaults
- GitHub Actions has read-only repository contents permissions.
- The workflow requires no secrets and the validator uses only the Python standard library.
- Never commit passwords, access tokens, private keys, or other credentials.
- GitHub handles account authentication and repository access controls.

## Reporting
Please contact the repository owner privately to report any sensitive security issue.
